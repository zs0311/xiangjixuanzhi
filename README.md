# 《项脊轩志》语文讲解网站

## 简介

这是一个基于Web的《项脊轩志》互动讲解网站，以古风庭院的形式呈现，通过小人（"我"）为线索，带领用户探索归有光的回忆。

## 功能特点

### 🏠 场景设计
- 完整的古风庭院场景，包含：
  - 白墙黛瓦的房屋（项脊轩）
  - 飘动的云朵和远处的青山
  - 庭院中的竹子、桂花树、枇杷树
  - 阳光照射的温馨氛围

### 📍 五个可探索位置
1. **项脊轩** - 归有光读书的书房
2. **庭院** - 月下读书的惬意时光
3. **祖母** - 祖母的关爱与期望
4. **母亲** - 母亲的牵挂
5. **妻子** - 妻子的音容与枇杷树

### 🎭 交互体验
- 点击场景中的图标查看对应位置的原文、翻译和讲解
- 小人（书生）会随着点击移动到相应位置
- 访问过的位置会显示绿色标记
- 顶部进度条显示探索进度
- 支持ESC键关闭面板

## 使用方法

1. 直接用浏览器打开 `index.html` 文件
2. 点击场景中的图标（📜🎋👵🌸🌿）
3. 阅读弹出的古文、翻译和知识讲解
4. 点击×按钮或按ESC关闭面板

## 技术实现

- 纯HTML/CSS/JavaScript，无需后端
- CSS绘制精美古风场景（房屋、树木、云朵、太阳）
- SVG绘制小人（书生）角色
- 流畅的动画效果（移动、脉冲、浮动）
- 响应式设计，支持移动端

## 《项脊轩志》原文

《项脊轩志》是明代归有光的名作，通过项脊轩这一小小书斋，回忆了作者少年时代的读书生活和家族往事。文章以项脊轩为线索，将对祖母、母亲的怀念和对妻子的悼念串联起来，以平淡的文字表达深沉的情感，是明代散文的精品。
